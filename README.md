# КартаЧек

Белый чекер и набор инструментов прокачки карточек офлайн-бизнеса в **Яндекс Картах, 2ГИС и отзовиках**.

## Что умеет MVP
- **Бесплатный рентген (до 3 точек):** индекс здоровья 0–100 по 20 факторам, светофор дыр, разрыв с лидером района и расчёт упущенных клиентов.
- **Умная вставка (`Ctrl+A → Ctrl+C → Ctrl+V`):** вставьте скопированную страницу своей карточки Яндекс Карт / 2ГИС — чекер автоматически вытащит рейтинг, отзывы, фото, галочку, устаревшие услуги, рекламу конкурентов и % ответов.
- **PRO (открыт бесплатно на время теста, с превью paywall):**
  - Генератор **печатного QR-тейблтента A5** и **Умного помощника отзыва (`?review=...`)** с тегами под нишу и мягким перехватом замечаний директору.
  - 3 готовых скрипта просьбы об отзыве под 9 офлайн-ниш РФ.
  - Конструктор живых **SEO-ответов на отзывы** + шаблон обжалования фейков.
  - Проверка названия на риск бана Яндекс Бизнеса, генератор **UTM-ссылок**, чеклист-план на 14 дней и сравнение всех точек.
  - Шаринг отчёта по ссылке (`#share=...`) и сохранение в PDF.

## Архитектура
Полностью статическое приложение без внешних JS-зависимостей (включая встроенный ISO/IEC 18004 QR-генератор) — работает на GitHub Pages и стабильно открывается в РФ.
